# TrustAdaptRL

Functional research implementation of **TrustAdaptRL: An Online Reinforcement Learning Framework for Attack-Resilient Trust Management in Fog-IoT Networks**.

## What is implemented

- Hybrid public-traffic-driven Fog-IoT simulation
- Dataset-agnostic preprocessing for TON_IoT, BoT-IoT, and IoT-23 tabular exports
- 5-cluster / 200-device configurable dynamic topology with lightweight Random-Waypoint mobility
- Grayhole, on-off, and collusion attack injection
- Simulator-generated trust/attack ground truth kept separate from dataset-derived security evidence
- State vector `[B, C, S, H, rho]`
- Factorized neighbour-wise trust actions: decrease / maintain / increase
- Attack-aware QoS reward shaping
- Tabular Q-learning and PyTorch DQN
- Replay buffer, target network, and fog-side training abstraction
- Trust-QoS-security next-hop routing
- Static weighted, Beta reputation, Dempster-Shafer-style, anomaly-threshold, QoS-only, and lightweight EigenTrust helpers
- Five-seed statistical evaluation utilities
- Intrinsic Q-table explanation and optional SHAP support for DQN

## Quick start

```bash
python -m pip install -r requirements.txt
python train.py --agent qlearning --steps 100 --max-devices 40
python train.py --agent dqn --steps 100 --max-devices 40
```

The quick-start mode uses synthetic traffic so the repository is immediately executable without downloading multi-gigabyte public datasets.

## Use a public dataset export

```bash
python train.py --agent dqn --dataset /path/to/TON_IoT.csv --steps 500 --max-devices 200
```

CSV, Parquet, and Pickle tables are accepted. Because the three public datasets have heterogeneous schemas, `UnifiedTrafficPreprocessor` projects available numeric flow/telemetry columns to a common normalized traffic representation and derives an imperfect anomaly score. The native attack label is **not** used as simulator trust ground truth.

## Compact reproducibility run

```bash
python reproduce_all.py
```

This runs Q-learning and DQN across the manuscript's malicious-node ratios and five seeds, then writes `outputs/tables/all_runs.csv` and `paired_statistics.csv`. For paper-scale runs, increase simulation steps and `max_devices` to the full 200-device setting.

## Configuration

See `configs/default.yaml`. It includes the manuscript's principal values: 5 fog clusters, 40 devices/cluster, 100 m communication range, 1000 time steps, 10-step windows, malicious ratios 0/10/20/33%, grayhole 0.45 default (within the 0.30-0.60 range), 50% on-off duty cycle, collusion groups of 3-5, Q-learning eta=0.10/gamma=0.95, and DQN LR=1e-3/gamma=0.99/batch=32/buffer=50,000/target update=20.

## Scientific-use note

The public datasets provide traffic/security characteristics only. Fog-IoT topology, routing interactions, forwarding outcomes, routing-specific attacks, and trust labels are generated by the simulator. This separation is intentional and should be preserved in any extensions.
